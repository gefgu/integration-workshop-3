# CP04 — Capsule greeting

**Win:** One capsule displays a real pt-BR greeting.

Build the assigned functional groups in the [assembly app](tscircuit/README.md). Earlier soldered wiring stays fixed. Removable links and top-side kit arrangements may change.

## Link positions

- Prototype source only: positive C2 / ground C1; final supply and matrix disconnected.
- OLED uses ESP1 GPIO4 SDA / GPIO16 SCL at 3.3V. Remove diagnostic probes before ordinary operation.
