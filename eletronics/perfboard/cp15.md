# CP15 — Bounded source and sink

**Win:** Smart output drives valid levels and limits short-circuit current.

Build the assigned functional groups in the [assembly app](tscircuit/README.md). Earlier soldered wiring stays fixed. Removable links and top-side kit arrangements may change.

## Link positions

- USB prototype source and prototype 3V3 links removed before final supplies connect.
- Use checkpoint-specific bounded test loads; stop and isolate power before changing any link.
- For smart-mode bench fixtures, disconnect both fixed battery leads and remove the initial kit loop. Output load: P3→1kΩ→LED anode, LED cathode→GND through removable leads. Logic inputs: HIGH=qualified3V3_SYS through1kΩ; LOW=GND through1kΩ. AND/OR exercise00,01,10,11; NOT exercise0,1. Never parallel another source with P3. Current tests use a documented series path, never an ammeter across the supply.
