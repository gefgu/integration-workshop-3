
                                -- processar a imagem --

PRÉ-PROCESSAMENTO (APLICA APENAS UMA VEZ, NO INÍCIO OU SOB AS CIRCUNTÂNCIAS ***):
1) aplica filtros para clarear e suavizar a imagem:
        1.1) Converte para escalas de cinza
        1.2) Limiarização adaptativa (adaptive threshold) OU detecção de bordas (Canny Edge) ->
        testar e ver quem funciona melhor
        1.3) Operações morfológicas de dilatação e erosão: para fechar possíveis buraquinhos nas linhas de contorno
        1.4) Identifica os 4 pontos de "quina" da protoboard
        1.5) Calcula a matriz de perspectiva de homografia a partir da 
        configuração desses 4 quadriláteros (deixar a protoboard o mais "quadrado" possível)
        1.6) A partir da imagem homografada "perfeita", calculamos as coordenadas
        "perfeitas" para identificar com PRECISÃO cada socket.

SALVANDO AS COORDENADAS DE CADA SOCKET:
        2.1) Fazemos a homografia reversa para identificar onde na IMAGEM REAL está
        cada socket (coordenada real). Armazenamos numa matriz 11 x 12 as coordenadas 
        correspondentes a cada um dos sockets na imagem que ESTAMOS VENDO

VERIFICANDO O COMPONENTE:
        3.1) Para saber o que tem dentro de um socket, basta observar a COR dele; 
        Pegamos um quadradinho de 5x5 pixels e calculamos a MÉDIA da coloração (em HSV).
        A média retornará a cor = componente.





A cada 1 segundo:
    1) aplica contorno na imagem inteira; 
    2) a partir da área do contorno, delimitar a protoboard.
    3) aplica transformação de perspectiva (usa matriz de homografia) para deixar a protoboard o mais "retangular" possível
    3) a partir do contorno da protoboard, guardar uma matriz de vetores 11 x 12 (cada posição representando um socket) com 
    as coordenadas centrais dos pixels de cada socket (da imagem original!)
        OU dá para definir 4 pontos limite dos sockets da protoboard (todos os outros estarão a um
        intervalo constante de distância na horizontal e na vertical)
    4) fazer um grid para identificar os pixels ocupados por cada socket.


A cada 200 ms:
# 4) verifica se houve mudança de coloração no grid (ou varredura para verificar as cores de cada socket).
        Se colorido:
        # 1 - identifica posição;
        # 2 - identifica componente (depois vemos como)
            # - se verde: led ou buzzer
            # - se azul : resistor ou capacitor
            # - se amarelo: botao ou potenciometro
            # - se branco: jumper
            # (a bancada é preta, então as cores não vão se confundir)[
