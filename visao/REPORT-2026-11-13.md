## Hypotheses evaluated

- **A:** Explicit stored camera controls and original-byte recording are used.
  Current controls are provisional and require bench calibration; this camera
  does not expose an auto-WB toggle. Restore commands must use stored values.
- **B:** The new profile uses one commanded exposure (1600 in these PC recordings),
  with no switching. A universal single exposure is **not proven**: fresh glare
  still causes refusals. No synthetic exposure is called a measured capture.
- **C:** Canonical geometry and tolerances use socket units; band colour uses
  body-relative brightness/chroma. Full board-reference Lab normalization has
  not been implemented or validated.
- **D:** Candidates have deterministic ordering and targeted overlap rules.
  A globally optimized board-level selector has not been implemented.
- **E:** Two-frame body confirmation/removal and separate sign confirmation are
  adopted. Values are re-read from each frame; no position/inventory value cache
  is introduced. A slow machine still needs actual latency verification.
- **F:** Only complete 220/470/1k patterns are decoded, with several rows/crops
  supplying positive evidence. There is no learned classifier or inventory fill.
- **G:** Positive printed-mark evidence identifies the capacitor; blue alone does
  not. Complete erasure of any required mark rejects its template.
- **H:** Raw decisions and polarity reasons are exposed. A complete reason code
  for every failed candidate/debug overlay is still unfinished.
- **I:** Opt-in original-byte recorder and exact-service replay are in use.

Root causes and changes driven by this recording:

- Left-edge red LED: the legacy fixed20-pixel horizontal correction rounded its
  positive lens/PCB evidence outside the grid. The opt-in board path uses the
  observed lens centre and the nearest valid two-pin footprint, retaining both
  positive PCB side checks. Battery/resistor-band negative tests pass.
- Reversed buzzer: add the missing mirrored foreground template and keep
  independent green-PCB support. The moved body scores .757; other valid slots
  in all three saved arrangements score at most .590. The body threshold is
  .72, with geometry guarded below the half-socket ambiguity boundary.
- Capacitor: all three printed marks matched, but a .30-row anchor displacement
  failed the previous strict .30-row inequality. The guard is .45 socket,
  still below the nearest-row ambiguity boundary. Allow each actual glyph two
  canonical pixels of resampling phase; every glyph still needs .70 correlation
  and real contrast. Erasing any required mark remains a negative.
- Smart housing: raster correlation alone does not generalize across banks.
  Add positive three-sided housing, a continuous dark aperture wider than one
  socket pitch and local contrast. In the recorded dark state the unchanged
  grey body reaches HSV S123,V26; Lab chroma avoids calling that paint saturated.
  The continuous-aperture check rejects the *real empty socket lattice*, which
  could otherwise imitate three grey rails and a dark panel. OLED text is not read.
- Upper1k flicker: dark blue reflections made a giant connected component and
  triggered a fixed y-crop that cut off the real bands. Measure the dense bright
  holder face locally instead. No value cache or inventory assignment was added.
- Plain blue holders can remain unknown bodies without requiring a grey ceramic
  gap. Generic body geometry never supplies a resistor value or capacitor type.
- Unknown-to-known confirmation keeps a positively seen body visible as unknown
  while its new type waits for the second frame, eliminating a one-frame hole.
